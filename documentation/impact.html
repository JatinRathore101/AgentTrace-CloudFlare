Users / accounts

  • Single-user demo. No auth. Anyone with the workers.dev URL can start runs and use the shared Neuron budget. 🟡 acceptable for a demo
  • One Cloudflare account (Jatin's) on the Free plan.

Data

  • One Durable Object instance, default, holds all runs. At about 30 spans per run and ≤ 32 KB per span payload, 1,000 runs stay far under the 1 GB agent cap. 🟡 estimate
  • No personal data. Tool data is mock data.

Risks and mitigations

RiskLikelihoodMitigation
vinext beta cannot export the TraceAgent DO from the custom worker entry, or breaks on MUI/Emotion SSR✅ resolved in 2.1Phase-1 spike, time-boxed to 1.5 h. Fallback: the agents-starter template (Vite + React SPA) with the same components (D3).
The 10 ms CPU limit per request on Free is exceeded by SSR🟡 mediumPages are "use client" shells. Route handlers only proxy to the DO. Payloads are capped (span I/O truncated to 32 KB).
The 10,000 Neurons/day budget is exhausted during development✅ likelyDevelop on Llama 3.1 8B via the MODEL_DEV var. Mock the AI binding in tests. Show a clear 'daily AI quota reached' error.
Llama ignores tools or returns malformed tool_calls🟡 mediumValidate the arguments with a small schema, record a tool_error span, cap the loop at maxSteps = 8. That is itself a failure AgentTrace shows.
Faults do not reproduce deterministically (model non-determinism)🟡 mediumFaults are injected in tool code, not only in prompts. Detectors read spans, not model intent. Use seed where supported.
@callable decorators fail under Vite 8✅ documentedAdd the agents() plugin from agents/vite, or avoid decorators by calling DO RPC methods from route handlers (the chosen design).
Worker bundle exceeds the size limit🟡 lowwrangler deploy --dry-run --outdir dist and check the size. Current limits page states 64 MiB.
Reviewers expect Workflows usage🟡 lowOptional stretch: move the agent loop into a Workflow with one step.do per step (todo stretch row).
