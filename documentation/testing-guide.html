Run locally

npx wrangler login        # once; local AI calls hit the real service

⚠️
Local runs spend real Neurons

Keep MODEL_DEFAULT on GLM 4.7 Flash while developing (measured 13–69 Neurons per run). A Llama 3.3 70B run measured 81 Neurons for the simplest scenario. Durable Object data is local only, stored in .wrangler/state/.

Demo script

  1. Open the runs list. Click New run → S1 lisbon-weekend, no faults → Start. Watch the timeline fill in.
  2. Open the finished run. Show the summary, the timeline, a tool span in the drawer, and the cost.
  3. New run → S1 with the loop fault. It ends as max_steps with loop + max_steps findings.
  4. On the failed run, open Ask AI → "Why did this run fail?" The answer cites the repeated searchFlights spans.
  5. Ask a follow-up ("How do I fix the tool?"). The history persists after a reload, which shows memory/state.
  6. Tick both S1 runs → Compare. Show the token and cost delta and the diverging steps.
  7. Optional: tool_error and stale_context runs to show the other detectors.

Calibration

  1. Run every scenario and fault combination 3 times with the loop below.
  2. Compare the result against the done criteria. Adjust the prompt, tool descriptions or thresholds, then repeat.
  3. Repeat once on Llama 3.3 70B. Budget: about 6 runs × 405 Neurons ≈ 2,430 Neurons.
  4. Export the 5 best runs with API 3 into src/agent/fixtures/demo-runs.json (todo 4.1).
# calibration loop (local, GLM 4.7 Flash first, then MODEL_DEFAULT=Llama 3.3 70B)
for f in none loop tool_error stale_context token_waste wrong_tool; do
  curl -s -X POST http://localhost:3001/api/runs -H 'content-type: application/json' \
    -d "{\"scenarioId\":\"lisbon-weekend\",\"faults\":[\"$f\"]}" | jq -r .runId
  sleep 30
done
curl -s 'http://localhost:3001/api/runs?limit=10' | jq '.runs[] | {scenario, faults, status, findings_count}'

Where to look when something breaks

  • Terminal running npm run dev: route and DO logs.
  • Production: npx wrangler tail agenttrace, Dashboard Observability, AI Gateway logs.
  • A 429 or quota error from Workers AI means the daily 10,000 Neurons are spent. It resets at 00:00 UTC (05:30 IST).
