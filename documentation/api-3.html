Lists saved runs, or returns one run with spans, findings and chat history.

Request

FieldTypeRequiredNotes

Response

FieldTypeNotes
runs[]Run summaryList: id, scenario, faults, model, status, steps, tokens, cost_usd, started_at, duration_ms, findings_count
runRunDetail: full runs row
spans[]SpanDetail: ordered by seq, I/O truncated to 32 KB
findings[]FindingDetail
chat[]ChatMessageDetail: oldest first

Errors

CodeWhen
404Run id not found

Flow

  1. stub.listRuns({ limit, status }) or stub.getRun(id).
  2. DO runs indexed SELECTs via this.sql.
  3. Return JSON. The UI computes waterfall offsets from started_at.

Sample curl

curl -s 'http://localhost:3001/api/runs?limit=20' | jq '.runs[] | {id, status, steps, cost_usd}'
curl -s http://localhost:3001/api/runs/<RUN_ID> | jq '{status: .run.status, spans: (.spans|length), findings: .findings}'
📌
Base URLs

Local: http://localhost:3001 (npm run dev:vinext) ✅. Production: https://agenttrace.<your-subdomain>.workers.dev. The subdomain is chosen in Setup 1 and becomes known after the first deploy. No auth: this is a single-user demo.
