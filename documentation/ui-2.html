Validation / edge cases

  • Bar x = (span.started_at − run.started_at) / run duration, width = latency. Minimum width 2 px.
  • LLM bars and tool bars use different colours. Error bars are red. Bars carry a #seq label.
  • Inputs and outputs over 32 KB show a "truncated" badge.
  • Ask AI is disabled while the run is running.
