API 2 — POST /api/runs

Starts a new traced agent run and returns at once. The loop continues inside the TraceAgent DO.

Request

FieldTypeRequiredNotes
scenarioIdstringyeslisbon-weekend | tokyo-weather | budget-check
faultsstring[]noDefault []. Any of wrong_tool, loop, stale_context, tool_error, token_waste.
modelstringnoDefault from the MODEL_DEFAULT var
goalstringnoOverrides the scenario goal (chat-style input), max 500 chars

Response

FieldTypeNotes
runIdstring (uuid)Use with API 3
status"running"Progress over WebSocket or polling

Errors

CodeWhen
400Unknown scenario, fault or model; goal too long
429Another run is still running (one at a time on the single DO), or MAX_RUNS_PER_DAY has been reached (resets 00:00 UTC)
500DO unreachable

Flow

  1. Validate the body.
  2. getTraceAgent() → stub.startRun(input).
  3. DO inserts a runs row (status running) and calls this.schedule(0, 'executeRun', { runId }).
  4. Return 202 { runId, status }. The loop runs as in agent loop.

Sample curl

curl -s -X POST http://localhost:3001/api/runs \
  -H 'content-type: application/json' \
  -d '{"scenarioId":"lisbon-weekend","faults":["loop"],"model":"@cf/meta/llama-3.1-8b-instruct-fp8-fast"}' | jq
📌
Base URLs

Local: http://localhost:3001 (npm run dev:vinext) ✅. Production: https://agenttrace.<your-subdomain>.workers.dev. The subdomain is chosen in Setup 1 and becomes known after the first deploy. No auth: this is a single-user demo.
