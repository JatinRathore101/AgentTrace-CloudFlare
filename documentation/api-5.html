Ask AI: answers a question about a run, grounded in its trace and findings, and remembers the conversation.

Flow

  1. stub.explain(id, message).
  2. Build the prompt from the template: compact trace, findings, last 10 chat messages.
  3. env.AI.run(model, { messages, max_tokens: 600 }, { gateway }).
  4. Insert the user and assistant rows into chat_messages. Return the answer.

Sample curl

curl -s -X POST http://localhost:3001/api/runs/<RUN_ID>/explain \
  -H 'content-type: application/json' \
  -d '{"message":"Why did this run fail?"}' | jq -r .answer
📌
Base URLs

Local: http://localhost:3001 (npm run dev:vinext) ✅. Production: https://agenttrace.<your-subdomain>.workers.dev. The subdomain is chosen in Setup 1 and becomes known after the first deploy. No auth: this is a single-user demo.
