Overview

  • Problem: agents can return HTTP 200 while calling the wrong tool, looping, using stale context or wasting tokens. AgentTrace makes those failures visible and explainable.
  • Assignment fit: Llama 3.3 on Workers AI (LLM) · Agents SDK TraceAgent Durable Object (coordination) · Ask-AI chat (input) · DO SQLite plus synced state (memory). ✅ confirmed
  • Stack: Next.js via vinext on one Worker, built from the companies-dashboard boilerplate. AI Gateway and Workers Observability are on. Everything stays on the Free plan. ✅ confirmed
  • Biggest risk: vinext is beta. Phase 1 is a 1.5 h spike with an agents-starter fallback. 🟡 open
  • Next step: finish todo section 1 (account, subdomain, wrangler login), then the 2.1 spike.
