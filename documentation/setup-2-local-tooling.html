Install

# Node 22 LTS via Homebrew (skip if node -v already prints v22.18+)
brew install node@22 && brew link --overwrite node@22
brew install jq

cd /Users/sanju/my-code/repos/ai-powered-application-Cloudflare
npm i -D wrangler@latest vinext vite @cloudflare/vite-plugin vitest @cloudflare/workers-types
npm i agents

Authenticate Wrangler

npx wrangler login      # opens the browser, approve access
npx wrangler whoami     # prints your email + Account ID
✅
Login is needed even for local dev

Workers AI has no local simulator. wrangler dev and the Vite plugin call the real service, which spends real Neurons and needs authentication.

Verify

node -v                       # v22.18.0 or newer
npx wrangler whoami           # shows the account
git -C /Users/sanju/my-code/repos/ai-powered-application-Cloudflare remote -v   # fetch https, push git@github.com
