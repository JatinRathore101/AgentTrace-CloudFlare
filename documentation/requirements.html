Non-functional / constraints

  • Cost: must run entirely on the Workers Free plan with no payment method. ✅ confirmed See free-tier budget.
  • Time box: 8–12 hours of AI-assisted coding. 🟡 estimate
  • Runtime: the Workers runtime, not Node. No native addons (for example better-sqlite3) and no fs. ✅ confirmed
  • Quality: TypeScript strict, Biome lint clean, Vitest unit tests for the pure logic.
  • Hosting: a single Worker on *.workers.dev.

Strict rules agreed for this task

  • Every prompt is recorded in prompt-history/<UTC timestamp>/prompt.md before it is acted on (repo CLAUDE.md, Rule 1).
  • Claude never stages or unstages files. Jatin stages, and commits go through the git-commit skill.
  • Documentation is local HTML in documentation/. No claude.ai artifacts.
  • Naming Cloudflare is allowed everywhere. The earlier Rule 2 was dropped on 25 Oct 2026.

Out of scope

  • Authentication, multiple users and multi-tenancy.
  • Real third-party tool APIs. The sample agent's tools are deterministic mocks.
  • Voice input through Realtime. Chat satisfies component 3.
  • Ingesting traces from external agents via an SDK or OTLP endpoint. Listed as a stretch goal in todo.
  • Workers Paid features: Tail Workers, more than 10,000 Neurons per day.
