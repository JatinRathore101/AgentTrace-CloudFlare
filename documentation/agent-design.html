📌
Mocks are deterministic

Tools return fixed data keyed by arguments, so the only non-determinism is the model. Fault flags change tool behaviour in code, which makes failures reproducible.

Agent loop

  1. Build messages: a system prompt (role, tool policy, "answer when done") plus the scenario goal.
  2. Call env.AI.run(model, { messages, tools, max_tokens: 1024 }, { gateway }). Record an llm span with usage, latency and the gateway log id.
  3. No tool_calls: finish as succeeded with response as the final answer.
  4. Otherwise run each tool call. Record a tool span (status ok/error) and append a role: "tool" message.
  5. setState progress, then repeat. After maxSteps = 8, finish as max_steps.
  6. On finish: run detectors, write findings, total the tokens and cost on the runs row.
// src/agent/runner.ts — shape of the loop (pseudo-TypeScript)
async function executeRun(run, ctx) {
  const messages = [system(scenario), user(scenario.goal)];
  for (let step = 1; step <= MAX_STEPS; step++) {
    const t0 = Date.now();
    const res = await ctx.env.AI.run(run.model,
      { messages, tools: toolDefs(run.faults), max_tokens: 1024, temperature: 0.2 },
      { gateway: { id: env.AI_GATEWAY_ID /* "default" */, metadata: { runId: run.id, step } } });
    ctx.recordSpan({ kind: "llm", name: run.model, input: messages, output: res,
      prompt_tokens: res.usage?.prompt_tokens, completion_tokens: res.usage?.completion_tokens,
      latency_ms: Date.now() - t0, gateway_log_id: ctx.env.AI.aiGatewayLogId });
    if (!res.tool_calls?.length) return ctx.finish(run, "succeeded", res.response);
    messages.push({ role: "assistant", content: JSON.stringify(res.tool_calls) });
    for (const call of res.tool_calls) {
      const t1 = Date.now();
      try {
        const out = await runTool(call.name, call.arguments, run.faults);
        ctx.recordSpan({ kind: "tool", name: call.name, input: call.arguments, output: out, latency_ms: Date.now() - t1 });
        messages.push({ role: "tool", name: call.name, content: JSON.stringify(out) });
      } catch (e) {
        ctx.recordSpan({ kind: "tool", name: call.name, input: call.arguments, status: "error", error: String(e), latency_ms: Date.now() - t1 });
        messages.push({ role: "tool", name: call.name, content: JSON.stringify({ error: String(e) }) });
      }
    }
    ctx.setProgress(run.id, step);
  }
  return ctx.finish(run, "max_steps", null);
}

As built

Tools are sent in OpenAI format (D24). MODEL_PARAMS in scenarios.ts adds chat_template_kwargs.enable_thinking=false for GLM (D25). parseModelReply accepts both the native and the OpenAI response shapes. The loop is started with this.schedule(0, "executeRun") (D26).

Cost estimate

// src/agent/cost.ts
export const RATES = {                     // Neurons per 1M tokens (Workers AI pricing page, 25 Oct 2026)
  "@cf/meta/llama-3.3-70b-instruct-fp8-fast": { in: 26668, out: 204805 },
  "@cf/zai-org/glm-4.7-flash":                { in: 5500,  out: 36364 },
} as const;
export const USD_PER_1K_NEURONS = 0.011;
export const FREE_NEURONS_PER_DAY = 10_000;

export function estimate(model: keyof typeof RATES, promptTokens: number, completionTokens: number) {
  const r = RATES[model];
  const neurons = (promptTokens * r.in + completionTokens * r.out) / 1_000_000;
  return { neurons, usd: (neurons / 1000) * USD_PER_1K_NEURONS };
}

Ask AI

  • Input: the compact trace from explain.ts plus findings plus the last 10 chat messages (memory). Kept under about 6,000 tokens to stay well inside the 24k context.
  • Model: the same model switch as runs. The answer is stored in chat_messages with its token usage.
  • Default question when the panel opens on a failed run: "Why did this run fail?"
SYSTEM:
You are AgentTrace's debugging assistant. You explain why an AI agent run behaved as it did.
Use ONLY the trace and findings below. Cite span numbers like [#4]. If the trace does not show
the cause, say so. Answer in at most 8 short bullet points, then one line "Fix:" with the change
to make (prompt, tool, or code).

TRACE (JSON, truncated fields end with "…"):
{ "run": { id, scenario, goal, faults, model, status, steps, tokens, cost_usd },
  "spans": [ { seq, kind, name, status, latency_ms, prompt_tokens, completion_tokens,
               input_excerpt (≤ 400 chars), output_excerpt (≤ 400 chars), error } ],
  "findings": [ { detector, severity, span_seq, message } ] }

HISTORY: previous chat_messages for this run (oldest first, last 10)
USER: <question from the Ask-AI panel, default "Why did this run fail?">
